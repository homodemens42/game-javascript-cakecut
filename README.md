# game-javascript-cakecut
# ケーキを切れる健康優良不良少年

指定された数に、できるだけ正確に切り分けるゲームです。

## 遊ぶ

👉 [GitHub Pages](https://homodemens42.github.io/game-javascript-cakecut/)

## 遊び方

1. お題の等分数を確認
2. マウスで切断線を引く
3. 「切り終える」を押す
4. 正確さと効率を確認

指定されたピース数になっていない場合は失敗です。

ケーキ以外の丸いものが出てくることもあります。

## 使用技術

* HTML
* CSS
* JavaScript
* Canvas API
* GitHub Pages
